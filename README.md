# Menu-BR

Инжектируемый ImGui-меню (`.so`) для **Black Russia** (`libblackrussia-client.so`,
Android ARM64). Оверлей рисуется поверх игры через PLT-хук на `glDrawElements`,
данные читаются из памяти игры через безопасные чтения с проверкой маппингов.

Проверено против сборки **16.110.18323** (build-id
`805be086548eb236ee469e88c11d5d3e66cfe1ba`) — бинарник лежит в `reference/`,
все адреса и сигнатуры в `src/off.cpp` сверены с ним (см. `tools/host_test.cpp`,
`make test`). Для **16.106.17587** используется таблица из RE-документации
(`reference/VEHICLE_STRUCTURE.md` и др.) + структурные пробы в рантайме.

---

## Возможности

| Вкладка | Что делает |
|---|---|
| **Свой** | Локальный игрок (ID, скорость, позиция, «в машине / пешком»). Локальный ID: «авто» (по умолчанию 411) или вручную. Телепорт по координатам мира (запись в `ped+0x38/0x3C/0x40`). |
| **Машины** | Перебор пула из 2000 машин (`net id`, класс, пассажир). Телепорт к выбранной, «сесть» (запись в поля игрока/машины/педа), двигатель ON/OFF (только 16.106 — метод `0x1b7f444`), «создать» (фабрика `0x1b815a0`, только 16.106, **экспериментально**). |
| **Игроки** | Список игроков (менеджер, 1504 слота), телепорт к игроку, «сделать локальным» (взять ID выбранного игрока как локальный). |
| **ESP** | 2D-радар (миникарта) на экране: игроки и машины вокруг, дальность, подписи (id/скорость), направление севера. Вкл/выкл слайдером. |
| **Net** | **Монитор синхро-пакетов**: счётчики пакетов/сек по ID (30 — игрок, 32 — машина, 33 — link, 34 — InCar, 38 — OnFoot, 39 — кран, 11 — RPC) для 16.110 через глобал `packetId @ 0x49C698` (эдж-детект ~500 Гц, без inline-хука). Справочник протокола. Ручные адреса для Custom-сборки. |
| **Settings** | Сборка: Auto / 16.106 / 16.110 / Custom. Прозрачность и масштаб меню. Лог: в файл / в окно / оба. Сохранение настроек (`/sdcard/brmenu/config.txt`), сброс, Rescan. |
| **Лог** | Цветной лог работы (E — красный, W — жёлтый). |

Отправку RPC **нет** (BitStream-макет отправляющего пакета по имеющимся данным
не восстанавливается) — вкладка Net показывает только приём/монитор и
справочник.

## Управление

- **Один палец** — мышь (тап/перетаскивание).
- **Два пальца** — колесо (вертикальный сдвиг центроида).
- **Горячая кнопка** «BR» (круг, перетаскивается, позиция сохраняется) —
  открыть/закрыть меню.
- Клавиатура (если устройство шлёт key events) — для InputText: A–Z, 0–9,
  Backspace, Enter, стрелки и т.д.

## Как устроено

1. **Загрузка.** `dlopen("libmenu-br.so")` + `MenuBR_Init()`, либо
   `System.loadLibrary("menu-br")` (тогда инициализация сама по `JNI_OnLoad`).
   Библиотека **не объявляет NEEDED** (только бionic-символы из глобальной
   области видимости процесса) и **не импортирует GL/EGL/android API** —
   всё берётся через `dlopen/dlsym` в рантайме (`src/glapi.cpp`).
2. **Определение сборки** (`src/detect.cpp`): build-id из
   `.note.gnu.build-id`, затем таблица адресов + структурные пробы
   (заголовки функций, глобалы из `.rela.dyn`) + сигнатурные сканы
   (`GetByNetId`, диспетчер синхронизации). Для неизвестной сборки — Custom:
   адреса вбиваются вручную во вкладке Net.
3. **PLT-хук** (`src/hooks.cpp`): в стабе `glDrawElements` (fallback
   `glClear` → `glDrawArrays`) переписывается только последний `br x17`
   на `b <trampoline>` (GOT не трогаем — без гонок). Трамплин — копия
   16-байтового стаба в RWX-странице рядом (±128 МБ, чтобы adrp остался
   в диапазоне). Дальше наш код рисует ImGui поверх кадра и вызывает
   оригинал.
4. **Чтение памяти** (`src/mem.cpp`): все чтения только после проверки
   диапазона в кэше `/proc/self/maps` — при вылетевшем указателе игра не
   падает (возвращаем 0/«не найдено»).
5. **Ввод** (`src/input.cpp`): `eglGetCurrentSurface` →
   `ANativeWindow_getInputQueue` → тред опроса AInputQueue.
6. **C++ runtime** (`src/rt_shim.c`): ImGui 1.91 — C++, поэтому библиотека
   собраны с `-fno-exceptions -fno-rtti`, а `operator new/delete`,
   `terminate`, `__cxa_pure_virtual`, `__cxa_atexit` предоставляет сам shim —
   импорты libc++ не нужны.

## Сборка

### 1) Zig (кросс-компиляция без NDK — как в этом репо)

```sh
ZIG=/path/to/zig ./build.sh zig     # → build/libmenu-br.so (aarch64)
```

В песочнице репо: `/tmp/zig15/lib/python3.11/site-packages/ziglang/zig`
(zig 0.15.2, ставится `pip install ziglang`). Компиляция идёт с glibc-
хедерами, но линковка — без libc: в `.so` **нет NEEDED**, все 58 UNDEF-
символов — стандартные bionic (`malloc`, `mmap`, `pthread_*`, `dlopen`…).

### 2) Android NDK (альтернатива)

```sh
export NDK=$HOME/Android/Sdk/ndk/28.2.13004772
cmake -B build/ndk -DCMAKE_TOOLCHAIN_FILE=$NDK/build/cmake/android.toolchain.cmake \
      -DANDROID_ABI=arm64-v8a -DANDROID_PLATFORM=android-24 -DCMAKE_BUILD_TYPE=Release
cmake --build build/ndk                    # → build/ndk/libmenu-br.so
```

### 3) Хост-тест (x86_64, без телефона)

```sh
make test   # компилирует src/ для хоста, проверяет ELF/PLT/сигнатуры
            # на reference/libblackrussia-client.so (16/16 PASS)
GAME_SO=/другой/путь/libblackrussia-client.so make test   # другая сборка
```

## Использование на устройстве

```c
// в любой точке процесса игры
dlopen("/sdcard/brmenu/libmenu-br.so", RTLD_NOW);
int (*init)(void) = dlsym(h, "MenuBR_Init");
init();
```

или из Java: `System.loadLibrary("menu-br")` (копия .so в `lib/arm64-v8a/`,
именнованная `libmenu-br.so`).

Остановка: `MenuBR_Shutdown()` — снимает хуки, останавливает треды,
вызывает `__cxa_finalize` для статических объектов.

## Адреса (VA внутри .so; base + VA = адрес в процессе)

### 16.110.18323 — сверено с бинарником

| Что | VA |
|---|---|
| `VehiclePool*` (2000 слотов × 8B) | `0x37FBEC8` |
| `PlayerManager*` (слоты `mgr+8+id*8`, id ≤ 1503) | `0x37FBEC0` |
| таблица педов (шаг `0xF8`, поз `+0x38/+0x3C/+0x40`) | `0x35C7A28` |
| таблица цветов (16B/игрок, RPC 401) | `0x37FC174` |
| `GetByNetId(u16)` | `0x1A1C1C8` |
| `GetPlayerById(id)` | `0x19F0E48` |
| диспетчер синхро-пакетов `f(w0,w1)` | `0x19D4664` |
| глобал `packetId` (у 16.110 — для монитора) | `0x49C698` |
| игрок: `CVehicle*` / флаг «в машине» / состояние (19=в машине) / u16 id машины | `+0x540` / `+0x548` / `+0x118` / `+0x150` |
| машина: пассажир / класс | `+0xB8` / `+0x430` |
| пед: u16 id машины | `+0x54A` |
| PLT: `glDrawElements` / `glClear` / `glDrawArrays` (стаб / GOT) | `0x22EA7E0/0x2415D28` / `0x22EA8A0/0x2415D58` / `0x22EA9A0/0x2415D98` |

Сигнатуры: `GetByNetId` — `28 3c 00 12 1f 3d 1f 71` (8B); диспетчер —
36-байтный пролог (единственный в `.text`), обе в `src/off.cpp`.

### 16.106.17587 — из RE-документации

Глобалы: pool `0x37809C8`, mgr `0x37809C0`, педы `0x354C5D8`, цвета
`0x3780C74`. Функции: `GetByNetId 0x19D2FDC`, `GetPlayerById 0x19AADA4`,
диспетчер `0x1990A78` (арг-регистры не подтверждены — монитор для 16.106
недоступен), `CreateVehicle 0x1B815A0`, метод двигателя `0x1B7F444`
(гипотеза). Поля игрока: `CVehicle* +0x148`.

## Ограничения и риски

- **Двигатель / спавн** работают только в 16.106 (в 16.110 методы не
  выделены — UI их скрывает). Спавн в 16.106 — экспериментальный.
- **Телепорт/посадка** пишут значения напрямую — без отправки
  синхро-пакетов, сервер может откатить (особенно посадку).
- **Монитор 16.106** недоступен (глобал packetId не выделен в таблице).
- Хук ставится на первый попавшийся из
  `glDrawElements/glClear/glDrawArrays` — если игра перестанет вызывать
  их из своего .so, оверлей не появится (Rescan помогает).
- При обновлении игры до новой сборки — добавьте её в `src/off.cpp`
  (build-id + адреса) или используйте Custom; автоопределение
  переключится само по build-id.
- Библиотека читает чужую память в рантайме — используйте на свой риск
  (нарушение ToS игры, риск бана аккаунта).
